# moldkit

Mold URLs and kit query parts with stable normalization.

**Site:** https://theworker02.github.io/moldkit/

## Install / run

```bash
git clone https://github.com/theworker02/moldkit.git
cd moldkit
node src/cli.js
node --test
```
